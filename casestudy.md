# StudentHub Product Management Case Study

# 1. Problem Identification

College students frequently miss hackathons, workshops, internships, placement drives, and club activities because information is scattered across multiple platforms including WhatsApp groups, Telegram channels, Instagram pages, and college notice boards.

This fragmented discovery process creates confusion and causes students to miss valuable opportunities.

---

# 2. User Research

A survey was conducted among college students to understand how they currently discover opportunities and what challenges they face.

## Research Method

Tool Used:

* Google Forms

Participants:

* 10 Students

Questions Covered:

* Event discovery methods
* Pain points
* Missed opportunities
* Preferred solution

---

# 3. Key Findings

### Finding 1

Most students discover opportunities through WhatsApp groups.

### Finding 2

Several students reported missing opportunities because information was spread across multiple channels.

### Finding 3

Students preferred a centralized platform where all opportunities could be accessed.

---

# 4. Product Vision

StudentHub aims to become a centralized opportunity discovery platform for students.

The platform allows users to:

* Discover opportunities
* Search events
* View event details
* Register for opportunities

through a single interface.

---

# 5. Feature Prioritization

Features were prioritized using the RICE framework.

| Feature                      | Priority |
| ---------------------------- | -------- |
| Event Registration           | High     |
| Search Opportunities         | High     |
| Event Feed                   | High     |
| Personalized Recommendations | Low      |

---

# 6. MVP Definition

Based on research and prioritization, the MVP includes:

* User Login
* Event Feed
* Search Opportunities
* Event Details
* Event Registration

The following features were intentionally excluded from the MVP:

* AI Recommendations
* Notifications
* Social Features

This decision reduced development complexity and focused on solving the core problem first.

# 9. Success Metrics

The following product metrics were defined:

### Activation Rate

Percentage of users viewing at least three opportunities.

Target:
70%

### Registration Conversion Rate

Percentage of users registering for events.

Target:
20%

### Weekly Active Users

Target:
500+

### User Retention

Target:
40%
